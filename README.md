# Predicting-Coronary-Artery-Disease through Machine Learning

## Project Overview
This repository contains my final-year Computer Science dissertation project focused on developing a supervised machine learning predictive model to identify the likelihood of Coronary Artery Disease (CAD). The project aims to leverage data preprocessing techniques, and exploratory data analysis (EDA) to optimize model accuracy and reliability.

The aim was also to experiment in testing whether Multi-classification and a reduced dataset that mimics the capturable data in a single GP appointment to see explore the full capabilities of this dataset.

## Methodology
This project utilised various industry standard libraries in machine learning, with an extreme focus on minimising data leakage while optimising results as similar research conducted on the same dataset lacked some validity.

To conduct this project the following stack was used
*  **Language** - Python, Streamlit
*  **Key Libraries** - Scikit-Learn, TensorFlow, Pandas, Matplotlib, NumPy

## Results
( These are the best Results of the top performing model overall (Random Forest) )

Multi-Classification results are not included as the results found were deemed insignificant, and indicates that there is a large gap for further improvement with more data and optimisation.

*  **Accuracy** - 86% (Full dataset), 91% (Reduced Dataset)
*  **Recall** - 92% (Full dataset), 89% (Reduced Dataset)
*  **Precision** - 81% (Full dataset), 90% (Reduced Dataset)
*  **F1-Score** - 87% (Full dataset), 90% (Reduced Dataset)
